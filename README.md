# Aakarim Tap

## How do I install these formulae?

`brew install aakarim/tap/<formula>`

Or `brew tap aakarim/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "aakarim/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
