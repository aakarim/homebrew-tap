# Aakarim Tap

## How do I install these formulae?

`brew install aakarim/tap/<formula>`

Or `brew tap aakarim/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "aakarim/tap"
brew "<formula>"
```

## OpenLore

`brew install aakarim/tap/lore` installs both binaries: `openlore`, the server, and `lore`, the client that connects synced sources (Claude Code memory, Git repositories, local folders) to a server. The cask is regenerated by OpenLore's release workflow on every release, so do not edit `Casks/lore.rb` by hand.
